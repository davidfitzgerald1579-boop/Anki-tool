Snip Occlusion — Getting Started

Snip a slide, box the facts, and let a free open-source AI draft the flashcards.

For version 0.28 · Anki 2.1.50 or later on Windows, Mac and Linux · Guide updated September 2026

Snip Occlusion is an Anki add-on for studying from slide decks. You take a screenshot of a slide, it appears in the editor, you draw boxes over the facts you need to recall, and one click makes the cards. Since version 0.28 it can also read the slide's text and draft question-and-answer cards for you, using an open-source AI that runs either on a free hosted service or on your own computer.

Fastest route RECOMMENDED

  • Install the add-on (section 1)
  • Make a free Groq account, paste the key (section 3)
  • Nothing to download; cards arrive in a second or two

Fully private route

  • Install the add-on (section 1)
  • Install Ollama and download a model, about 5 GB (section 4)
  • Nothing ever leaves your computer; a minute or so per slide on a laptop

1. Install the add-on

  1. Get the code or the file. On AnkiWeb, the add-on has a numeric code shown on its page. In Anki choose Tools → Add-ons → Get Add-ons…, paste the code and press OK.
    No code yet, or installing from GitHub? Download snip_occlusion.ankiaddon from the project's Releases page at github.com/davidfitzgerald1579-boop/Anki-tool/releases, then use Tools → Add-ons → Install from file… and pick that file.
  2. Restart Anki. Add-ons only load at start-up. After the restart, the Tools menu has two new entries: Snip Occlusion — New from Clipboard… and Snip Occlusion — Write a Text Card….
  3. Updating later. If you installed with a code, Tools → Add-ons → Check for Updates fetches new versions. If you installed from a file, install the newer file the same way; your settings, saved API keys and the AI's learned examples are kept.

2. Your first cards from a slide

  1. Open the editor. Press Ctrl+Shift+O in Anki's main window (or Tools → Snip Occlusion — New from Clipboard…).
  2. Snip a slide. Use your normal screenshot tool — Win+Shift+S on Windows, Cmd+Ctrl+Shift+4 on a Mac. The snip lands in the editor by itself, straight from the clipboard.

    The editor: yellow masks (a group shares a bold outline colour), a selected box, a grey cover-up box that erased a line of text, and a snip patch parked beside the slide.

  3. Box the facts. Press R and drag a box over each thing you want to recall — or simply double-click a word to box exactly that word. Press C to draw a cover-up box that erases irrelevant text (it is filled with the slide's background colour).
  4. Group boxes that should be revealed together. Shift-click each box, in any order, then press G. Shift-click never moves anything.
  5. Pick a deck and a mode. Hide All, Guess One masks everything and highlights the target; Hide One, Guess One masks only the target.
  6. Add Cards (or Ctrl+Enter). One card per group. The editor clears, ready for the next snip.

    Question side: the target group in red, everything else masked.

    Answer side: the target revealed; other masks can be clicked to peek.

Cards work everywhere. They are plain HTML, so they review correctly on AnkiDroid and AnkiMobile with nothing installed on the phone.

3. AI-suggested cards with Groq — no download

The add-on can read a snip's text and draft question-and-answer cards. The quickest way to run the AI is a hosted service: the same open-source model runs on that company's computers instead of your laptop, so drafts arrive in a second or two. Groq is the recommended first choice — no card details, a free daily allowance that covers over a hundred slides, and very fast. The add-on itself stays free; you never pay us anything.

  1. Create a free Groq account and an API key. Go to console.groq.com/keys, sign up (email or Google/GitHub), press Create API Key, give it any name, and copy the key. It starts with gsk_. Keep it private, like a password.
  2. Open the add-on's settings. In the Snip Occlusion editor, press the ⚙ button (top right of the view toggle). The window scrolls; Save and Cancel stay at the bottom. F11 makes it full screen if you like.
  3. Choose "A hosted service", paste the key, test. Under AI model for card suggestions pick A hosted service. Groq is already selected in the Service box. Paste the key into API key, leave the model as suggested, and press Test connection.

    A successful test: ✓ Groq answered with openai/gpt-oss-20b in 0.6 s. The note underneath spells out exactly what is sent where.

  4. Save. That's the whole setup. From now on, the moment a snip lands in the editor the add-on reads its text and starts drafting cards in the background, so they are usually ready before you finish drawing boxes.
What is sent, and what it costs. With a hosted service the slide's text is sent to that service — never the image — along with a few of your kept cards as style examples. Groq's free tier allows roughly 200,000 tokens a day per model, which is over a hundred slides; beyond that Groq charges a fraction of a cent per slide, billed by Groq to your Groq account. If you would rather send nothing anywhere, use section 4 instead.

OpenRouter, Together AI, Hugging Face, Ollama Cloud, Mistral, Fireworks, DeepInfra and Cerebras are offered the same way: pick the service, press Get a key ↗, paste, test. ↻ Fetch list shows every model the service currently offers; bigger models such as gpt-oss-120b write noticeably better cards and are still fast.

4. Keeping everything on your own computer (optional)

Skip this section if you set up Groq. Choose it instead if you want nothing to leave your machine: the same open-source model runs locally through Ollama, free, with no account and no key. The trade-off is speed — a laptop CPU takes a minute or more per slide (a computer with a gaming GPU, or an Apple-silicon Mac, takes a few seconds).

  1. Install Ollama from ollama.com/download (Windows, Mac, Linux). It runs quietly in the background.
  2. Download a model once. Open a terminal (Windows: search for PowerShell; Mac: Terminal) and run:

    ollama pull llama3.1:8b

    About 5 GB; it needs roughly 8 GB of RAM to run. On a low-memory machine use ollama pull llama3.2:3b instead (2 GB, faster, slightly weaker cards).
  3. Choose "On this computer" in ⚙ Settings. This is the default, so a fresh install is already set. Press ↻ Fetch list to see the models you have downloaded, pick one, press Test connection, then Save. The first answer after Ollama starts can take a minute while the model loads; later ones are faster.
Switching later is one click. The Settings window remembers a model and key for each option separately, so you can move between the local model and a hosted service whenever you like — a key entered for one service is never sent to another.

5. Using the suggestions

  1. Open the Suggested Cards view. After snipping a slide, use the view toggle at the top of the editor to switch from Image Editor to Suggested Cards. The status line says where the AI is working ("generating via Groq…" or "generating on your machine…"); the drafts appear underneath, with the slide's text alongside.
  2. Judge each draft. Use → opens the card in a small window for a quick edit before adding it. ★ keeps it as a great example without adding. 👎 flags a poor card so the AI avoids that habit. ✕ simply discards. The AI learns your taste from what you keep and reject.
  3. Ask for cards about one passage. Highlight any sentence in the slide's text, right-click, and choose ✨ Make a card from this selection. Pick how many cards you want.
  4. Paste a whole lesson. The 📋 button takes a pasted document and generates cards section by section, streaming them in as they are ready.
  5. See where a card came from. The 🔎 button on a draft highlights the sentences it was written from. Cards you add keep that link: while reviewing, 🔍 Reveal source on the card's back shows the whole slide and the highlighted source text — on your phone too.
Invented citations are caught. If a draft cites a case, statute or year that is not in the slide's text, the add-on strips it from the notes or marks the card with a ⚠ warning, so you never memorise an authority the AI made up.

6. If something goes wrong

What you seeWhat it means and what to do
"…edge network (Cloudflare) blocked the request… error code 1010"Your copy of the add-on is older than 0.28.1, which identifies itself properly to Groq's network. Update the add-on. If it persists, a VPN or shared network is the usual cause — try another connection.
"…rejected the API key (HTTP 401)"The key is wrong or was deleted. Make a new one at the service's key page (the Get a key ↗ link in Settings), paste it, and Test connection again.
"…rate-limiting you (HTTP 429)"You have hit the free tier's per-minute or per-day allowance. Wait a little, pick a different model (each has its own allowance), or switch service.
"…could not find that endpoint or model (HTTP 404)"The model name has changed — services retire models now and then. Press ↻ Fetch list in Settings and choose a current one.
"Could not reach the Ollama server…"Ollama is not running or the model is not downloaded. Start Ollama, run ollama pull llama3.1:8b, then press Test connection.
"…is not downloaded yet. In a terminal run: ollama pull …"Exactly that: run the command shown, wait for the download, try again.
"The local model took too long to reply"Normal on the first request after Ollama starts. Try again; if it keeps happening use a smaller model, or a hosted service (section 3).
Suggestions say "no snip text"The slide's text could not be read. On Windows the built-in OCR is used; on Mac and Linux install Tesseract (brew install tesseract / apt install tesseract-ocr) and restart Anki.
The Settings window's Save button is off-screenUpdate to 0.28.2 or later: the window now scrolls and Save stays visible. F11 toggles full screen.

Still stuck? Report it on GitHub with the exact message: github.com/davidfitzgerald1579-boop/Anki-tool/issues. Reviews on AnkiWeb can't be replied to, so GitHub is the place where you'll get an answer.
